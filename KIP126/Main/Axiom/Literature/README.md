# Main/Axiom/Literature

本目录保存 A(M) 的原始来源、固定制品、清单与适用范围说明。准确的数学 statement 是根 `Challenge2.LiteratureInterface` 的字段；Main 仅通过 `Main.StageInput` 从唯一阶段见证投影这些字段。本目录不再逐项声明独立 axiom。

`SourceApplicationData` 和 `Inputs` 的语言在 Def；它们不是整体阶段输入。`quotient_algebras` 只交付各商的交换代数及单位；球作用和所选限制映射的乘法相容由内部适配提供。模型绑定、来源特化中的实质适配及本文新结果由 Main/Solution 负责。来源定位、强度和证据状态见 [A 输入](/docs/A_INPUT_FREEZE.md) 与 [本轮自审](/docs/audits/stage0-57647d2-iteration-3.md)。
