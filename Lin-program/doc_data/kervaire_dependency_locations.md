# Kervaire 论文中 Lin Program 的依赖位置

本文档列出 Kervaire 论文 [arXiv:2412.10879](https://arxiv.org/abs/2412.10879) 中程序依赖出现的位置，以及每个位置读取的计算结果。

## 1. 引言中的明确说明

论文第 1 节“证明策略”中的 Lin’s Program 小节明确给出四类作用：

1. 计算大量有限谱的 Adams (E_2) 页；
2. 计算这些谱之间的 (E_2) 页映射；
3. 对某些有限谱计算 Adams (d_2)；
4. 用 Leibniz 规则、自然性和扩张谱序列传播微分和扩张。

同一小节进一步说明：结合广义 Leibniz 规则和广义 Mahowald 技巧，程序会检查相关条件并生成可读证明；在 stem 125 的 105 个 (h_6^2) 潜在目标中，程序与归纳方法共同排除 101 个。

这一位置确定了 Lin Program 在全文中的角色：它提供 Adams 谱序列的有限计算数据和机器推导，供第 7 节的合成谱及同伦论证使用。

## 3. 附录中的程序数据位置

第 8 节的标题是：

```text
The classical Adams spectral sequence in the range
122 <= t-s <= 127, s <= 25
```

附录明确指出，传播程序依赖三类数据：

- 一组 CW 谱的 Adams (E_2) 页；
- 这些 (E_2) 页之间的映射；
- 某些 CW 谱的 Adams (d_2)。

附录表格的覆盖范围如下：

| 表 | 对象 | 范围 |
|---|---|---|
| 1 | (S^0/\nu) | stem 126，(9\leq s\leq14) |
| 2 | (S^0) | stem 122，(s\leq25) |
| 3 | (S^0) | stem 123，(s\leq25) |
| 4 | (S^0) | stem 124，(13\leq s\leq25) |
| 5 | (S^0) | stem 124，(s\leq12) |
| 6 | (S^0) | stem 125，(20\leq s\leq25) |
| 7 | (S^0) | stem 125，(s\leq19) |
| 8 | (S^0) | stem 126，(11\leq s\leq25) |
| 9 | (S^0) | stem 126，(s\leq10) |
| 10 | (S^0) | stem 127，(21\leq s\leq25) |
| 11 | (S^0) | stem 127，(10\leq s\leq20) |
| 12 | (S^0) | stem 127，(s\leq9) |

每个表的列为：

```text
s | Elements | d_r | value
```

其中：

- `d_r` 表示正向微分；
- `d_r^{-1}` 表示反向使用微分信息；
- 空白项表示永久循环；
- `?` 表示程序没有确定具体值；
- `possibly` 表示只确定了候选集合或附加项。

## 4. 三条手工输入

附录还标出三条不是程序自动算出的微分：

```text
d5(h0^24 h6) = h0^2 P^6 d0       （S0）
d6(h0^55 h7) = h0^2 x_{126,60}    （S0）
d3(v2^16)     = beta^5 g          （tmf）
```

后续形式化时应将它们建模为带来源说明的外部定理或人工输入，而不能标记为普通 `Adams` 自动输出。

## 5. 依赖关系的最小闭包

若只为了形式化 Kervaire 论文的程序部分，第一批 Lean 证书不必覆盖全部 49 个谱和全部证明数据库。最小闭包是：

```text
S0、S0/nu、tmf 的相关局部 E2 数据
        ↓
附录表 1–12 中实际引用的微分和永久循环
        ↓
Fact 7.6、7.13、7.15、7.19、7.21
        ↓
Proposition 7.8 和 Proposition 7.9 所需的计算前提
```

这组结果足以覆盖论文中 Lin Program 直接参与的计算性接口；广义 Leibniz 规则、广义 Mahowald 技巧和最后的合成同伦论证属于后续独立形式化任务。
