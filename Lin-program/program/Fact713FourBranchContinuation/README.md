## Lean results

The four case modules prove old/new cross checks, full family coherence,
counts, and entry inclusion for both parents. `Branches.lean` unifies
these results for both Boolean parameters and proves the bound finite E10
trajectory and exact missing keys. The imported full comparisons use the
parents' kernel-checked `lin_cert` proofs; no checksum is a mathematical
premise.

`Actual.actual_local_selection` retains the arbitrary entire row3136
source matrix, row3135 product derivation, whole target meaning, row3305
same-element naming, square zero, and full incoming meaning. It returns
one merged finite branch with the corresponding complete local actual
matrix equations. `Actual.actual_row3143_column` retains its independent
source homology, product, known-differential, naming, and quotient inputs.

The actual E10 interface requires a `Prefix10 S pages`, whose complete
neighboring meanings and quotient laws are explicit. It does not derive
those meanings from finite family coherence. A requested theorem can be
proved from an imported strict request and this same actual prefix:

```lean
import Fact713FourBranchContinuation.Request
open Fact713FourBranchContinuation
open Fact713Row3143Continuation.Constructed

example (r a : Bool) (P : Prefix10 S pages) :
    RequestedValid r a P ActualTraceRequestsE10.e10 := by
  fact713_four_branch_cert using P
```

The tactic also supports batches. It proves family coherence, exact finite
trajectory binding, and the imported actual E10 request together. The
request uses the stable existing `ActualTraceRequests` JSON schema:
version, claim `fact-7.13:E10`, source `[true,true]`, and output `[true]`.
For failures, use `ActualTraceRequests.diagnose` or `diagnoseBatch` with
`ActualTraceRequestsE10.spec` to locate the field and record. Use
`IndexedFamilyCertificates.diagnoseFamily` for a malformed finite family.
These explicit diagnostic functions support the parameterized interface;
the generic closed-check tactic is not advertised for a free actual prefix.

## Reproduction and evidence

`generate.py` reuses the frozen row3136 generator with exact textual
anchors, adds the independently proved row3143 rule, asserts all parent
overlap records agree, and recomputes the whole graph. `package.py` asserts
that the resulting new records exactly equal the row3143 extras. The
recomputation finds no additional complete blocks beyond this union.
Four stable family JSON files are exported. The merged Lean modules reuse
the exact parent comparison definitions rather than reparsing duplicates.

```sh
python3 program/Fact713FourBranchContinuation/generate.py
python3 program/Fact713FourBranchContinuation/package.py
python3 program/Fact713FourBranchContinuation/audit.py
python3 program/Fact713FourBranchContinuation/reproduce.py
python3 program/Fact713FourBranchContinuation/compile.py
python3 program/Fact713FourBranchContinuation/freeze.py
```

The independent audit checks every matrix, full chain homotopy identity,
all cycle-pair quotient fibers, all predecessor dimensions, all ordered
family pairs, and exact parent records and provenance. Direct Lean
compilation is serial and records source, dependency and observed-result
hashes. Failed historical attempts are retained separately and never used
as accepted evidence. Reproduction compares every generated byte.

This package checks finite data and proves conditional actual transport.
It does not construct the Adams sequence from original topology, infer
cycles from raw NULL schedules, prove the RP1_8 branch-exclusion premise,
or claim unconditional Kervaire conclusions. The accepted Lean results
use no proof holes, custom axioms, native evaluator, or implicit trust in
C++; only the standard `propext`, `Classical.choice`, and `Quot.sound`
are permitted by the final axiom audit.
