# Named Cnu bottom-cell class on the finite d2 homology

An existing generic batch comparison at metadata index1955 already covered
Cnu degree(14,139). The missing named conclusion is now checked in
`BottomCell.lean`: the class h1 h4 x109,12[0], local2/global4412, is a
cycle, not a d2 boundary, and has E3 quotient coordinate(0,1). The entire
finite d2 homology is equivalent to two Boolean coordinates, with representatives
e0+e1 and e2. `targetClass_nonzero` proves nonzero in the actual quotient
type, not merely nonzero of the input vector.

The certificate was generated by the existing C++
`PageTransitionCertificates/page-transition-export`. `source.json` records
the exact command arguments, SHA-256, and all source/target SQLite rows;
`comparison.json` is imported canonically and verified by Lean.
Outgoing d2 sends local0 and local1 to local4 and sends local2/local3
to zero; incoming d2 has only its local2 column nonzero, equal to local3.
Thus the named local2 survives the finite quotient.

Only genuine non-NULL d2 TEXT entries were used. Empty TEXT is the zero
vector in the SQLite exporter format. No higher differential was supplied
or assigned zero. This result does not prove non-hit through d5 or
Proposition7.9; identifying imported d2 with the actual topological
Adams differential is also separate. The existing CnuBottomCell module
supplies the named module-expression interpretation of local2.

From the repository root:

```
python3 program/CnuPageCertificates/review.py --check
```

Omitting `--check` is also read-only. The script verifies the pinned DB
SHA-256 and all three complete basis blocks, reconstructs the matrices,
calls the existing C++ exporter, and requires byte-identical certificate
output. Four negative cases ensure NULL, `[NULL]`, `-1`, and `?` fail.
No Lean files or wire certificates change during this check.

Explicit regeneration is available with `--regenerate`; it replaces only
`comparison.json` after the same pinned-source validation. Recompile
`BottomCell.lean` after regenerating. This reproduction check verifies
source identity and finite certificate inputs, not topological Adams
correctness or any unknown higher differential.
