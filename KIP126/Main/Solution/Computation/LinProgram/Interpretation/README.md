# 固定计算交付的消费解释

本目录使用同一个 Challenge 2 见证提供的 presentation、基坐标、标准类比较和表格结论。
标签与实际模型的认证由 Interface 负责；这里保留其投影及 Main 推论。

- [Basis](Basis/README.md)、[Expressions](Expressions/README.md)、[Classes](Classes/README.md)：基、坐标及类。
- [Presentation](Presentation/README.md)：已交付比较的代数推论。
- [Differentials](Differentials/README.md) 与 [Selected](Selected/README.md)：记录语义及六条 lookup 推论。
- [Differential](Differential/README.md) 与 [Tower](Tower/README.md)：页面微分、长层及实际塔推论。

Selected 的七条原始元数据在 `LinProgram/Generated/Selected/records.json`，
与这里的六条条件证明分开保存。Main 中间定理的陈述与证明只在 Solution 维护，只有最终目标与 Challenge 配对；
lookup 成功不会自动推出后续页面非零或永久存活。
