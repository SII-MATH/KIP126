# Induced map export

Build and test from program:

```sh
g++ -std=c++17 -O2 -Wall -Wextra -Werror PageTransitionCertificates/induced_export.cpp -o PageTransitionCertificates/induced-export
python3 PageTransitionCertificates/test_induced_export.py
PageTransitionCertificates/induced-export 1 4 1 0100 1000 1 4 1 0100 1000 1000010000010010 1 1
PageTransitionCertificates/induced-export --batch input.txt
```

A record has exactly 13 whitespace-separated tokens:
`K M N OUT IN L Q P TARGET_OUT TARGET_IN MIDDLE UPPER LOWER`.
All matrices are dense row-major bit strings; use `-` for a zero-size matrix.
Source dimensions are K x M and M x N; target dimensions are L x Q and Q x P.
Middle is Q x M, upper L x K, and lower P x N. Dimensions are at most 256.
Both complexes and both commuting squares are checked before output. Every
source/target comparison is generated by the deterministic Gaussian producer.
Batch errors include the line and failures in a square include its coordinate.
Empty input, blank lines, extra tokens, and malformed dimensions/bits fail.

Output is canonical JSONL for `WireInducedMap`, with sorted fields lower,
middle, source, target, upper, version. Source/target contain complete comparison
certificates. `induced_map% "path.json"` imports one record, and
`example : imported.Valid := by lin_cert using ()` proves validity in Lean.
`WireInducedMap.onHomology` and `.coordinates` connect that validity proof to
the actual quotient map and its coordinate formula. File elaboration does not
register Lake dependencies, so rebuild after changing input files.

The independent Python suite enumerates all 128 scalar source/target/maps,
accepting 38 and rejecting 90, and tests zero dimensions, malformed input,
canonical determinism, batch completeness and error line numbers. The producer
is outside Lean's trust root; each generated certificate must still be checked.
