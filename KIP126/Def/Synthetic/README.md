# Synthetic 背景

本目录定义同一 H𝔽₂ 背景上的 synthetic category、ν、λ、双分次球谱、λ 幂商及其 ρ/δ 映射，以及内部三分次 Adams 家族。普通对象、νX 和有限商的映射都必须来自同一组函子和余纤维构造。

ν-cofiber、Bockstein、未截断 lift、过滤和 realization 的结论不因对象存在而自动成立。BHS 来源命题保留 nilpotent completeness、强收敛等相应条件；到所选路线对象的运输、检测与 lift-image 比较是独立证明责任。通用语言在 Def，交付合同在 [Interface/Challenge](../../Interface/Challenge/README.md)。

具体模型构造、λ 作用与 deformation 的识别、完成及比较证明仍需完成。不得把这些证明责任、指定微分或永久存活封装成默认实例。
