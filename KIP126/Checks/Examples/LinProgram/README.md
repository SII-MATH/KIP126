# Lin 数据接口示例

本目录随 Lin 输入与解释一并管理，用小表演示数据如何构成模型、以及如何在给定表示证据时用于实际 E₂ 页。示例中已有的定理仍是定理，移入 Axiom 所属目录不改变其性质。

## 1. 原先期望包含什么

- 用最小例子说明表的覆盖范围、模型环及表示接口。
- 用真实发布数据的有限样本演示基、乘法与非零性的使用方法。
- 保持“模型中计算成立”和“模型正确描述实际页面”的前提边界。

## 2. 现在包含什么

| 文件 | 用途 |
| --- | --- |
| [AdamsE2Table.lean](AdamsE2Table.lean) | 三格点人工表，检查 `x² = y`、模型非零性以及覆盖范围外不会被填零 |
| [AdamsE2LowDegrees/Data.lean](AdamsE2LowDegrees/Data.lean) | 已发布 t261.2 数据的小样本：86 个格点、27 个基向量和乘法记录 |
| [AdamsE2LowDegrees.lean](AdamsE2LowDegrees.lean) | 模型内乘法推导，以及给定 `Presentation` 后向实际页面传递的条件结论 |

低次样本使用源码注明的 t261.2 `S0_AdamsE2_csv.zip`，由 [提取脚本](../../../../scripts/extract_adams_e2_low.py) 重现；与当前 [Raw](../../../LinProgram/Raw/README.md) 中固定 v126.3.cw49 的五个输入分别记录，不把二者默认为同一版本。使用说明见 [E₂ 表接口](../../../../docs/ADAMS_E2_TABLE.md)。

公开声明名仍保留 `KIP126.Examples.*`，只有文件及 import 模块路径迁到此处。这里没有新增项目 axiom；实际页上的结论仍要求调用者提供 `Presentation` 或其存在性证明。

## 3. 大概完成度

**三个既有示例文件已全部迁移，声明与证明正文保持不变。** 已有例子覆盖表内计算和条件性解释；不据此估算第一阶段的数学验证完成度。它们没有给出固定表描述实际 Adams 页的完整证明。

## 4. 接下来还需要完成什么

- 保持样本版本、来源摘要、提取脚本与使用说明一致。
- 公共数据接口变化时同步检查例子，并保留未知范围与非法输入的边界。
- 若计划统一样本版本，单独审核数据变更；此次迁移不替换数据。
- 表到实际页面的证明交由相应阶段任务完成，不在示例中补造证据。

## 5. 后续应该一步一步如何做

1. 先读最小人工例子，确认覆盖范围和模型／页面接口。
2. 再读低次样本及其对应使用定理，核对实际需要的表示前提。
3. 修改接口后编译两个示例入口；修改数据时额外用固定版本提取脚本核验。
4. 有关真实页面的证明进度记录在 Interface 对应模块，不把示例编译通过计作前提已证明。
