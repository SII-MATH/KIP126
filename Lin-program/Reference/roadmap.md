# Kervaire 论文中 Lin Program 依赖概念路线图（步骤二，重新整理）

本文件只整理 Kervaire 论文中实际使用 Lin Program 的局部链条，不试图覆盖
Kervaire 论文的全部几何、流形或手术理论。目标是为后续 Lean 形式化提供一份
可审查的数学依赖清单：每个节点都是一个应当单独定义、单独说明语义、必要时
单独证明基本性质的数学对象或命题。

## 1. 范围与边界

Kervaire 论文的程序性核心是第 7 节附近关于 h_6^2 的 Adams 谱序列计算，以及
Lin Program 对微分、永久循环和扩张的排除。这里纳入：

- 有限表示、F_2 线性代数和可执行的稀疏数据；
- 链复形、同调、上同调、模 2 Steenrod 代数和 A 模；
- 自由分辨率、Hom 复形、Ext 和 Adams E_2 页；
- Adams 谱序列的页、微分、被击中、存活、乘法和自然性；
- 余纤维扩张谱序列中的 filtration、essential/inessential extension、
  crossing/no-crossing；
- Lin Program 的输入表、候选生成、广义 Leibniz/Mahowald 规则、证明树和
  可检查证书；
- Kervaire 局部使用的 101 个目标排除、h_6^2 存活、Fact 7.6 的四个局部事实。

这里不纳入：

- Kervaire 不使用 Lin Program 的几何背景；
- 论文中与上述程序结果无直接依赖的流形、手术和一般稳定同伦叙述；
- C++ 实现细节、数据库存储引擎和 Lean 语法本身。

## 2. 读图方法

依赖边 A → B 表示：在数学语义上，定义或陈述 B 时必须先有 A。
U 层是本科数学叶节点；其余层按可形式化的语义顺序排列。

层次顺序：

→ L 有限表示与计算对象

## 17. 步骤三语义审查补充节点

形式化审查发现，原路线图把“同调类”写得过于简略。为使后续 Lean 定义与
自然语言严格对齐，C 层的同调路径应展开为：

```text
C01 链复形
  → C02 循环元素
  → C03 边界元素
  → C04 边界是循环
  → C05 循环元素的“相差边界”关系
  → C06 自反/对称/传递性
  → C07 同调商类型（同调类）
```

对应实现是 `Cycle`、`HomologyEquivalent`、`homologySetoid` 和 `Homology`。
同样，R 层的分辨率微分必须沿 `term (s+1) → term s`，增广必须沿
`term 0 → target`；这已经反映在 `FreeResolution` 的类型中。该补充不改变
论文范围，只把原来合并的数学小概念展开为后续可检查的依赖节点。

## 19. 本轮形式化发现并补入的依赖

按依赖顺序实现时发现，原图中以下节点虽然有名称，却没有足够的中间数学对象：

- W11/W12 不能只写“映射锥/余纤维”，还必须先有生成粘合关系、等价闭包、商类型、商拓扑和商映射连续性；这些概念现由 `TopologyConstructions.lean` 显式给出。
- E05 的“下一页是同调”必须展开成循环子类型、入射边界、循环代表等价关系、等价关系证明和商类型；这些概念现由 `AdamsHomology.lean` 给出。
- E12–E15 的乘法规则需要双次数单位、结合、交换等式及其搬运函数，否则 Leibniz 公式的两项甚至不在同一个载体中；这些概念现由 `AdamsRules.lean` 给出。
- X07–X11 的扩张语义需要一个实际的过滤交换群和关联分次商，不能用代表值不相等来定义 crossing；这些概念现由 `FilteredExtensions.lean` 给出。
- W24–W27 不能用 `Unit` 或常值函数冒充球谱和 ν；因此新增了真实单位球面载体、Hopf 公式、逐级悬挂映射、映射锥商和稳定茎同伦商。稳定茎的交换群运算还必须由球面的 pinch 映射构造，不能凭空指定。

因此，路线图中这些节点的直接依赖已经从“程序记录”细化为上面的数学构造。当前
Lean 已经有真实球面、Hopf ν、Cν 第 0 级和稳定茎商的载体；但 Cν 的全谱结构映射、
稳定茎的 pinch 加法、Adams 收敛到这些真实对象以及 Kervaire 的具体 Ext 类仍需后续
形式化，不能因载体已定义就声称这些高阶定理已经证明。
