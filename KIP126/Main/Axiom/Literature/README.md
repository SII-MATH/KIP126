# Main/Axiom/Literature

显式接受有原始来源的 A(M)。`Source.lean` 接受同一标准球谱背景中的经典和 tmf 来源存在命题，`Synthetic.lean` 在同一 SourceModel 上接受十四个外部叶子，`Range.lean` 接受独立消失线和真实过滤分离性，`Moss.lean` 接受固定实际映射塔上的收敛命题。

`SourceApplicationData` 和 `Inputs` 的语言在 Def；它们不是整体公理。`quotient_algebras` 仅接受各商的交换代数及单位；球作用和所选限制映射的乘法相容由内部适配提供。模型绑定、来源特化中的实质适配及本文新结果由 Main/Solution 负责。来源定位、强度和证据状态见 [A 输入](/docs/A_INPUT_FREEZE.md) 与 [本轮自审](/docs/audits/stage0-57647d2-iteration-3.md)。
