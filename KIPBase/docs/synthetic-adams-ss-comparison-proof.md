# λ-Bockstein 与 synthetic Adams 比较：更正后的证明路线

## 强制路线约束

λ-Bockstein 在本项目中必须定义为乘 λ 的余纤维三角

```text
Σ^{0,-1}X →[λ] X → X/λ →[δλ] Σ^{1,-1}X
```

中边缘映射 `δλ` 所诱导的 extension spectral sequence。形式上应当使用

```text
SyntheticExtensionData (lambdaBocksteinConnecting X)
```

及其已有的 `SyntheticExtensionData.ess` 构造。

严禁改走 exact couple 路线，包括：

- 不新增 exact couple 抽象；
- 不从商对象塔另造一套谱序列；
- 不把 exact couple 当作证明微分相容性的中间接口；
- 不用 exact couple 解释或替代文献中的边缘映射 ESS。

有限 λ 商塔只用于证明边缘映射 ESS 与 synthetic Adams 页之间的提升、
障碍和自然性结论；它不是本项目中 λ-Bockstein 谱序列的定义。

本记录取代此前“由 E₂ 对象同构直接递归得到所有页同构”的报告。
此前报告没有证明微分相容性，还混淆了乘 λ 的扩张谱序列与 λ-Bockstein
谱序列，不能视为数学证明或 Lean 完成记录。

## 1. 首先校正比较对象

项目的 `Synthetic/ExtensionSS.lean` 中，`LambdaExtensionData` 是
`SyntheticExtensionData (lambdaPow n X)`；`lambdaESS` 是相应滤过二项复形
的扩张谱序列。其起始对象是两个 synthetic Adams E∞ 项，微分保持
homotopy stem，从复形次数 1 指向次数 0。

需要与 synthetic Adams 比较的 λ-Bockstein 谱序列，是乘 λ 的余纤维
三角中边缘映射 `δλ : X/λ ⟶ Σ^{1,-1}X` 所诱导的扩张谱序列。
有限商 `X/λⁿ` 及其限制映射用于证明这个 ESS 的页面比较。
文献定理 3.8 讨论前者；命题 4.2 说明乘 λ 幂的扩张谱序列只有 d₀
可能非零。这一区别必须先在定义中体现。

参考：[Lin–Wang–Xu，§3 定理 3.8、§4 命题 4.2](https://arxiv.org/html/2412.10879v2#S3)。

此前 `Rigidity.lean` 把 `lambdaESS … .Page 2 (s,1)` 与经典 Adams E₂
相连，不能充当 λ-Bockstein 比较的正确起点。当前工作树已把该既有
E₂ 输入改指向 `lambdaBocksteinESS`，并把错误的 weight 零截面修正为
对角次数：Bockstein 固定次数为 `(t-s,t)`，synthetic Adams 次数为
`(s,t,t)`。这属于修正既有公理的对象，没有增加公理。

## 2. 页码、分次和完整的起始页

用 Bockstein 的通常页码：第一页来自模 λ 对象的同伦群。
它对应 synthetic Adams 的第二页。Bockstein 长度 r−1 的微分
对应 synthetic Adams 的 dᵣ。

在项目的 (s,t,w) 次数约定下，Bockstein 的 λ 滤过为 t−w，
homotopy stem 为 t−s。λ 滤过增加 r−1，同时 stem 降一，因此
Adams 滤过增加 r，内部次数增加 r−1，weight 不变。
这恰好给出 synthetic Adams 的微分次数 (r,r−1,0)。

必须比较完整的三分次起始页和有次数的 λ 作用。经典 E₂ 的生成元
位于 weight 等于内部次数的对角线上；其他非零权重由非负次 λ 幂产生。
只在 weight 零处写一个对象同构通常是错误的，既没有记录这些结构，也没有给出
所有次数上的微分目标比较。对负内部次数还必须检查消失范围，不能
无条件把 weight 零截面认作整个经典 E₂。

代码中的 `lambdaBocksteinConnecting_naturality` 已直接由 functorial
cofiber 的第三个交换方块证明：它使用 `lambdaPow_naturality`，没有把
微分相容性作为输入，也没有使用 exact couple。

## 3. 真正需要证明的有限层引理

核心引理应当在取页同调之前证明，并且要有以下三个结论。

1. **循环与提升。** 初始类的 Adams 微分在 d₂ 至 dᵣ₋₁ 上消失，
   等价于相应的模 λ 类可以提升到模 λ 的 r−1 次幂。
2. **目标歧义。** 两个这样的提升所得连接映射值的差，在初始页
   目标中属于已经积累的边界；更换初始代表元产生相同的商关系。
   要证明边界子对象的实际对应，不能只证明两种目标空间维数相同。
3. **微分相容。** 在上述目标商对象中，对提升施加有限商三角的
   连接映射，等于 Adams 微分通过比较映射后的值。

这三条合起来才提供“页映射与微分交换”。

## 4. 如何证明有限层引理

从定义 synthetic Adams 微分的同一套分辨数据出发，在每一层同时
施加乘 λ 幂和取余纤维。λ 自然性给出原始方块；余纤维的自然性
给出包含、限制、连接映射之间的交换方块。对这些方块取同伦群，
得到用于追踪代表元的正合图表。

这里需要明确证明两个不同操作相容：横向沿 Adams 分辨提升代表元，
纵向沿有限 λ 商提升代表元。不能把已经需要证明的页微分交换式
作为图表的一条输入边。

逐层追图表：

- 一次提升失败的障碍是对应连接映射的值；正合性给出“障碍为零
  当且仅当能够提升”。
- 两次提升的差在限制映射的核内，因而来自正合图表前一项。
  继续追踪该差，识别它在目标上的像就是较短微分造成的歧义。
- 将同一代表元沿图表两条路径计算，原始方块的自然性使结果一致；
  连接映射的符号须统一。在模 2 情形符号不改变结果。

合成 Adams 的消失范围在此用于排除图表中额外的关联分次项，
使上述提升和障碍识别能够落在指定次数。特别是模 λ 的有限次幂
所对应的有限权重条带，以及模 λ 对象只在对角线上的集中性，
比单独“对角线上方消失”更强。必须列明追图表每一步用到的零项，
不能把任意提升声称为唯一，也不能从抽象对象同构推断图表自然。

这给出了有限层引理的证明任务与证明机制；本项目尚未完成该图表
及三条结论的 Lean 实现。这里没有把它们重新包装成未经证明的结构字段。

参考：[Burklund–Hahn–Senger，附录 A.1 的有限余纤维与 Adams 塔比较](https://arxiv.org/html/1910.14116v3#A1.SS1)。

## 5. 然后才是抽象谱序列归纳

归纳不变量应同时包括：当前页比较、循环和边界的对应，以及
代表元提升和连接映射的相容性。

起始页使用正确对象上的 E₂ 识别。应用有限层引理，得到本页
微分交换方块；因而比较映射把核送到核、把像送到像。
由此取商得到下一页同构。`pageHomologyIso` 正好将这一取商步骤
与项目中的下一页对象相连。

下一页的比较按诱导同调映射定义，避免独立选择一个抽象同构。
有限层提升的相容性也必须传到下一步，才可以重复归纳。

这一证明只涉及给定有限页所需的有限层图表，不要求全局 boundedness，
也不需要把 λ 变成可逆元。若还要比较极限、收敛目标或乘法，必须另外
验证相应的相容性，不能只凭逐页对象同构自动宣称这些结论。

## 6. 实施顺序与当前状态

1. 区分乘 λ 自身的扩张谱序列与边缘映射 `δλ` 所诱导的 λ-Bockstein ESS。
2. 校正 E₂ 比较所指的对象、完整分次和 λ 作用；涉及公理改动需报告审批。
3. 检查 synthetic Adams 的定义接口是否实际提供构造上述图表所需的
   分辨、位移、余纤维和同伦群联系。当前 `SynAdamsSS` 是不透明公理，
   “函子性”也只逐个给出态射；不能宣称展开这个公理就能取得分辨。
4. 在基础构造上证明有限层引理，把所需的消失结论逐项用于图表。
5. 复用抽象页同调接口，完成保持加强归纳不变量的逐页比较。

此前新增的短复形同调同构引理、交换方块传递同构引理以及两个
E₂ 公理的复合，均未证明第 4 项。本文件是经过定义与文献核对的
证明路线，不能记作最终比较定理已经证明。
