# Bounded source d5 search

This is untrusted search evidence, not an accepted actual d5 proof. The three
scripts preserve raw records and give physical CSV start/end line numbers.

The exact source-cycle argument occurs in proofs-part1.csv at physical
lines 1425546-1425547, event721501. Multiplication by g at (4,24) sends the
named Csigmasq E2 basis7441 at (14,154) to zero. Its possible d5 target
basis8097 maps to basis12881 at (23,182). The next event721502 records zero
d5, and event721503 transports it to S0. Those recorded events are search
clues; their presence is not a theorem.

The complete E2 product columns reduce to [e0+e1,0,0,0,0,0] at the source
and [e0,0,e8,0,0,0] at the target. The generated finite graph has 73 complete
comparisons among 96 attempted positions. Several coefficient d2 values are
outside the raw coverage bound177, and other incoming columns are NULL.
These missing values remain unresolved. No incomplete target matrix is used
as an injectivity certificate.

The separate Fact762SphereGDetection package investigates the same g rule
directly on sphere classes, where the relevant coefficient d2 data is
available. It has independent ownership and records its own remaining
mathematical conditions. This directory modifies no frozen source package.
