# 低次 E₂ 样本数据

## 1. 原先期望包含什么

保存可追溯的有限 E₂ 数据样本，供上层使用示例检查查询、乘法和解释接口。

## 2. 现在包含什么

[Data.lean](Data.lean) 保存 t261.2 发布数据提取的 86 个格点、27 个基向量、乘法记录、覆盖范围及模型元素。来源和摘要写在文件开头；上层 [README](../README.md) 说明它与当前 Raw 版本的区别。

## 3. 大概完成度

既有样本已完整保留；文件迁移没有变更数据或补充数学结果。样本不独立证明其描述实际 Adams 页面。

## 4. 接下来还需要完成什么

保持固定样本、提取脚本和覆盖范围约定同步；版本统一及表示证据的证明仍需独立任务。

## 5. 后续应该一步一步如何做

1. 根据源码记录定位固定归档，并用提取脚本检查数据区块。
2. 公共 Table 接口改变时编译本文件与上层使用示例。
3. 若修改覆盖范围或版本，在单独变更中核验数据及其消费端。
